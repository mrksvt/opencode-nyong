# Uninstall PlantUML Skill for OpenCode

To remove the skill and all its assets:

```bash
rm -rf ~/.config/opencode/skills/plantuml-skill
```

This removes:
- The skill file (`skills/plantuml-skill/SKILL.md`)
- All assets, examples, and references
- The `bin/plantuml.jar` offline renderer
- Documentation (`docs/`)
